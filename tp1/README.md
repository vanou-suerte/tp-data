# TP1

## Prérequis

- **Python**
- **[uv](https://astral.sh)** (gestionnaire de paquets et d'environnements Python ultra-rapide). Suivez le guide d'installation [ici](https://docs.astral.sh/uv/getting-started/installation/)

## Installation

1. **Installer les dépendances :**
   Grâce au fichier `uv.lock`, `uv` va créer automatiquement l'environnement virtuel (`.venv`) et installer les versions exactes des bibliothèques requises :

   ```bash
   uv sync
   ```

## Utilisation

1. Ouvrir le notebook et choissisez l'interpréteur Python générer avec uv précédemment (tp1)
